## ⚡ How to Deploy on Vercel

You can deploy this static portfolio to Vercel in 2 simple ways:

### Method 1: Deploy via GitHub (Recommended)
1. Initialize a git repository and push your portfolio to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: NLP Retro-Log Portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/nlp-retro-portfolio.git
   git push -u origin main
   ```
2. Go to [https://vercel.com](https://vercel.com) and log in.
3. Click **"Add New..."** -> **"Project"**.
4. Import your newly created repository (`nlp-retro-portfolio`).
5. Vercel automatically detects the static HTML configuration (and uses `vercel.json`).
6. Click **"Deploy"**! In ~15 seconds, your site is live with a free SSL domain (e.g., `https://nlp-retro-portfolio.vercel.app`).

### Method 2: Deploy using Vercel CLI (Instant from Terminal)
1. Install Vercel CLI globally (if you have npm/Node):
   ```bash
   npm i -g vercel
   ```
2. In this folder (`nlp-retro-portfolio`), simply run:
   ```bash
   vercel
   ```
3. Follow the quick terminal prompts:
   - Set up and deploy? -> `Y`
   - Which scope? -> Select your account
   - Link to existing project? -> `N`
   - What's your project's name? -> `nlp-retro-portfolio`
   - In which directory is your code located? -> `./`
4. For production deployment, run:
   ```bash
   vercel --prod
   ```
